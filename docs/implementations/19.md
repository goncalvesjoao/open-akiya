## Implementation

The worker accepts an optional private `confirmedDuplicateOf` observation claim. It requires nonblank evidence and an existing offer from another source with the same transaction type. It rejects unresolved claims and conflicting relinks. An established source key retains its projection when later observations omit the claim. Similar titles, locations, native IDs and URLs never establish a match.

The primary source keeps its attribution and business fields. Each source retains independent normalized fields, availability and successful-check time in SQLite. Availability remains supported until every source explicitly withdraws. The displayed successful-check and last-seen times use the oldest source check, retaining null for unknown legacy checks. This deliberately remains conservative when primary business facts remain displayed after withdrawal or a failed check.

An additive private history table retains successful observation snapshots and seeds existing saved observations on upgrade. Observation, history, offer key, projection and counters commit in the existing transaction. Renderer DTOs do not change. Editorial and legacy private fields remain preserved by the existing listing merge.

The parent synchronized the optional private observation field and validation rules into #5's authoritative contract before publication. There are no approved deviations.
