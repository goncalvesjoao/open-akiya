## Implementation and decisions

Saved results include municipality-only offers when documented synthetic reference regions intersect the selected area, independently of the representative point. The deterministic fixture reference regions, identities, intersection formula and municipal-office provenance are documented in [the sample map guide](../synthetic-map.md#synthetic-municipality-reference-evidence). The #5 representative-point recipe (35.1, 135) deliberately lies outside the default 5 km selected circle.

The sample import adds municipality offers, including unavailable and missing-point examples. Explicit synthetic source evidence marking a published point as the municipal office becomes the existing municipality location variant in the adapter. It never becomes an individual listing pin. The shared DTO remains unchanged.

Purple rectangular municipality summary markers show visible counts and open/focus the corresponding expandable group. Group offers select shared details and validated source links. Counts are built after availability filtering. Each offer appears once in the companion results list; list-only groups receive no invented marker. English explanations distinguish representative points from exact locations and unknown listing distances; original Japanese names remain collapsed and unchanged. Source-point uncertainty behavior and the selected-area import journey remain intact.

No approved deviations. Real municipal geography, geocoding, translation, live sources, unknown-location handling and aggregate parent completion remain outside this ticket.
