## Implementation and decisions

Private SQLite checkpoints use source, exact query scope, adapter version and date field. Reliable descending date evidence is validated on every received page, including cross-page order. Scans consume ties and inclusive overlap, then stop strictly below the saved completed boundary. Missing, invalid or inverted dates disable optimization and promotion. Initial and unrelated scopes cannot borrow dates.

Merged main `d7ade81` to integrate #20 freshness, #21 request ownership, #22 refresh scheduling and #23 continuation. Removed the duplicate fixed-24-hour stale-offer scanner: all older-offer checks now use the shared configurable, oldest-first refresh queue and its existing budgets and reservation. Discovery completion remains separate from independent old-offer refresh failure; those failures keep job/source outcomes partial or failed, successful-check evidence unchanged and checkpoint/cache promotion disabled. Three refresh-capacity assertions now reflect complete discovery after those detail failures, retaining their existing error, count, timestamp and terminal outcome assertions. Rejected newly discovered candidates and source limitations still leave coverage partial.

Bounded continuation restores ordering dates and discovery completion, and retains completed source traversal records across generations. All inherited required detail work must commit before promotion. Invalid/expired cursors and source-limitation restarts abandon newest/last dates; existing previously completed stopping boundaries remain usable. The replacement traversal independently earns its new boundary. Source semantic changes create independent evidence. Candidate writes and final checkpoint promotion retain transaction rollback protection. Renderer DTOs expose neither cursors nor checkpoint records.

No approved deviations. No live source transport or live inventory is enabled; source-declared ordering of unseen pages remains an adapter evidence requirement. Completion of this ticket alone does not complete parent #6/#3 or live-source acceptance.
