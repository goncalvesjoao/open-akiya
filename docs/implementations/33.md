## Implementation and decisions

Supported nonintersecting selections settle without export traffic and report why no export was requested. Existing normalization, bounded snapshot acquisition and worker transport from #34/#35 remain authoritative. Discovery requests only the allowed municipal export; embedded rows do not invent detail traffic. Date-based stopping and date checkpoint advancement remain disabled.

The [reference review](../research/tsubata-geographic-reference.md) pins the official N03 2026 archive and GeoJSON checksums, code/name crosswalk, scoped reuse conditions and local setup. The earlier unresolved distribution condition is resolved for this local-only architecture through GSI's private/internal-use guidance: each user acquires the reference independently; neither geometry nor derived real marker coordinates are bundled or committed. This does not grant public redistribution clearance. No alternative spec or source-activation permission was needed.

A worker-only local file loader verifies the pinned bytes and municipality identity, computes circle/polygon intersections and derives a reproducible point on surface with edition/hash/algorithm/CRS/source/license/processing provenance. Its composed options keep discovery and saved-results grouping on the same reference/version. Missing or invalid reference configuration fails closed. The desktop's synthetic default remains unchanged; live activation still requires #36's access, identity and residential eligibility gates.

The approved verification seam is the worker job API with temporary SQLite, controlled clocks and synthetic HTTP. Synthetic polygons cover edge/corner touches, holes, uncertainty, nonintersection and unsupported reference input. The private official reference is additionally checked manually without live listing requests or distributed geometry. January 2026 geometry is edition-specific and may contain provisional boundaries; numerical JGD2011 geographic use with a conservative tolerance is not cadastral precision. Municipality-only offers imply neither exact in-circle membership nor home distances.

No approved deviations.
