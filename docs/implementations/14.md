## Implementation and decisions

Worker-only additive offer-key and observation tables distinguish provider, native ID and transaction type, including sale/rent variants sharing a URL. Legacy listing UUIDs, raw private fields, primary attribution and unknown historical timestamps remain intact. The original listing and observation tables remain retained. New records use an internal listing UUID in the legacy uniqueness column; approved source references retain the provider's native ID. No uncertain cross-source merging is introduced.

Authoritative patches preserve omitted fields and require nonempty field-specific provenance for explicit null removals. Unknown availability cannot resurrect withdrawn offers. Unknown location requires removal evidence to replace known location. Blank or whitespace-only incoming text patches are rejected across every business text field; existing records are not scrubbed or rewritten during reads. Invalid normalized values count as checked/rejected and retain the previous record; genuine storage failures roll back the complete transaction and fail the job. This deliberately extends issue 13’s earlier zero-area failure expectations into per-offer rejection outcomes. Updated/unchanged outcomes compare effective approved business facts, independent of adapter hash and check timestamps. Observation, projection, outcome counters and candidate completion remain one transaction. Repeated discovery identities count once per provider/native-ID/transaction tuple.

Source availability remains independently saved per offer; unavailability affects default visibility, while failed checks and scoped omissions retain previous evidence. Proven cross-source reconciliation remains issue 19's scope. Editorial/private legacy fields stay in SQLite and never enter renderer projections.

No approved deviations. The confirmed test seam is the local worker API with temporary SQLite and deterministic synthetic adapters. One legacy fixture inspects its saved private editorial fields because the approved DTO deliberately excludes them; no production inspection API was added.
