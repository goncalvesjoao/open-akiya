## Implementation

The renderer follows server-returned active queue ordering and immutable job areas, exposes cancellation independently for every accepted request intent and each queued/running job, retains terminal history and counts, and refreshes current-area saved results at settlement. Running cancellation remains pending until the worker returns a terminal outcome. Stale polls cannot overwrite a newer action response. Minimal retained request IDs allow request cancellation after renderer reload; worker snapshots remain authoritative.

No approved deviations. Full interruption recovery, refresh and continuation controls remain sibling-ticket scope. Scheduling, attachment and ownership policies remain in the existing worker; no contract changes were required.

The Electron test uses a four-second detail delay guarded by unpackaged test mode, a test-data path and hidden-window flags.
