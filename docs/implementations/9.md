## Implementation

Synthetic discovery includes in-circle source points with both unknown and approximate precision as plausible candidates. Normal desktop sample imports now save these shared deterministic fixtures alongside the existing verified sale offer. The renderer draws separate amber, dashed square question-mark pins, labels both list entries and shared details **Location unverified**, distinguishes precision, and explains that true distance and radius membership remain uncertain. Numeric distance remains exclusive to verified positions.

Pin/list selection shares details and selected state. Coincident uncertain offers remain individually reachable through the list. Japanese source text, successful-check timestamps, validated source navigation and Show unavailable retain their existing behavior. Querying or navigating never starts collection. The shared DTO, source coordinates and worker saved-results filter remain unchanged.

## Decisions and scope

- The worker explicitly opts into the sale and uncertainty fixtures; the synthetic adapter's one-offer default remains for focused runtime durability tests. Fixtures have fixed coordinates and identities, never positions inferred from the selected area.
- No optional coordinate distance is displayed for uncertain candidates, avoiding an additional number that could imply verified membership.
- Coincident uncertain markers overlap; the companion list is the supported way to reach every offer. Nearby verified and uncertain fixture pins remain visually distinct.
- No approved deviations. Municipality summaries, unknown-location offers, geocoding, translation, live adapters and parent-spec completion remain outside this ticket.
