## Implementation and decisions

`src/main/tsubata.ts` normalizes permitted factual CSV records through the existing adapter and transactional storage boundary. One charged discovery response supplies embedded details without row-level traffic. Municipality code, municipal ID and transaction type distinguish offers sharing the export URL. Duplicate/conflicting identities and exact address/structure rekeys are quarantined, never fuzzy merged. Optional shared identity witnesses, source attribution, stricter pacing and municipality reference injection are documented in the owning runtime spec.

Only explicit residential structure strings naming 住宅/居宅 qualify. Integer yen, explicit free and evidenced monthly rent are validated; unknown fields preserve valid existing values. Explicit contracted status retains unavailable history, while omission and failed checks preserve saved offers. Coordinates remain absent. Allowlisted factual values, license/attribution, adapter version, hashes and check/field provenance stay worker-private as appropriate. No approved deviations.

## Limitations

The adapter is unregistered and unsupported by default. Live activation requires reviewed municipality geography, safe identity evidence, usable residential offers and the separate pilot. Fixtures use fictional intersection evidence with null representative points. Exact witnesses can quarantine legitimate coarse-address collisions/corrections and cannot detect simultaneous ID/address changes; they establish no temporal ID guarantee. Coverage remains partial. Snapshots are cached per worker execution, without durable byte continuation. The ten-second source interval is a conservative local policy. No live requests or collected records were used.
