## Implementation

Implemented a globally oldest-first refresh queue with configurable 25% detail-attempt reservation, release of unused capacity in both directions, durable class accounting and deferred work. Retries, redirects and conditional attempts retain their originating class and total cap. Shared detail handling preserves atomic observation/projection/count commits. Worker API tests use deterministic adapters, controlled clocks and temporary SQLite. Unsupported-geography adapters never enter pre-discovery refresh. No approved deviations.

Explicit continuation is owned by #23. The one-request alternating-class joint verification with that slice remains pending until its API is available; no completion of #6 or #3 is claimed.
