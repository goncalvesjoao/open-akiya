## Implementation and decisions

The real Tsubata adapter retains fully acquired, parsed CSV snapshots privately in SQLite. SHA-256 fingerprints, source/query/parser/reference versions, acquisition times and manual-refresh cutoffs govern reuse. Explicit Continue resumes compatible processing; incompatible or missing snapshots trigger an explained bounded full acquisition. Last-Modified is never a strong snapshot identity. Terminal jobs remain immutable, and cancellation never automatically resumes work.

Worker transport accounts for physical attempts and acquired bytes, enforces deadlines through response-stream consumption, serializes town requests with at least ten seconds between attempts, respects Retry-After, and permits only the published CSV URL. Access blocks stop execution. Invalid rows retain valid committed offers and truthful rejected counts; malformed headers, truncation and oversize responses cannot establish complete coverage or reusable snapshots. No date checkpoint is advanced for this source.

Limits are 262,144 bytes per response, a default cumulative 5 MB per job, at most 1,000 acquired CSV rows and a configurable row-processing budget. The chunk crossing a byte ceiling remains counted truthfully before acquisition stops. A shared export supplies per-offer successful-check evidence without fictional detail requests. Freshness, manual-refresh follow-ups and pending work use the existing job API and policies.

Integrated the completed #18 recovery/fencing prerequisite and the committed #34 factual normalization prerequisite, including its reviewed address-evidence refactor. See [18.md](18.md) and [34.md](34.md). Snapshot acquisition now serves that real adapter rather than a parallel DTO or normalizer. Shared contracts were updated in the owning runtime and policy specifications.

No approved deviations. Live activation remains gated by reviewed geography and the separate pilot requirements. Tests use fictional geographic reference evidence and source-shaped synthetic HTTP responses; no live-source requests were made.
