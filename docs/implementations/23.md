## Implemented behavior and decisions

`createImportRequest({intent:'continue', fromJobId, idempotencyKey})` derives area and retained source traversal from the terminal job. A private unique SQLite generation record and request idempotency are committed with the linked job in one immediate transaction. Retried keys recover their request; separate clicks share one job and every linked request receives its terminal outcome. Original terminal jobs remain unchanged.

Each continuation gets zero local counters and fresh configured budgets, while retaining discovered/completed offer identities, source traversal snapshots, pending candidates and completed-source outcomes. Cancelled jobs remain stopped until a new explicit action. Queued cancellation preserves already completed sources. Active jobs reject with `JOB_NOT_TERMINAL`; jobs without pending/restartable work reject with `NOT_CONTINUABLE`. Availability reflects actual retained work for partial, failed and cancelled outcomes.

Unavailable saved sources fail configuration validation. Changed source semantics restart affected discovery with an explanation, retaining committed identities/results. Source order is derived from immutable saved scope, including legacy progress recovery. Invalid/expired cursors reset only discovery traversal, preserve identities, expose a reason and consume the existing budget; this is a bounded continuation safeguard, not the full #26 freshness/checkpoint integration.

Shared full response recipes are in `src/shared/continuation-fixtures.ts`. Worker scenarios use temporary SQLite, controlled clocks and synthetic transport through the confirmed worker API seam in `src/main/continuation.test.ts`. No new renderer control or transport API was introduced; #31 owns the control.

The existing multi-source tests lacked controlled waits and timed out before the required two-second host interval. They now use the existing `testClock`, retain real request accounting, and assert actual resulting check times. An all-source parse-rejection expectation now says failed, matching #16's no-useful-current-run outcome; retained prior projections remain asserted unchanged.

No approved deviations.
