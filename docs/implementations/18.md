## Implementation and decisions

Fence rejected transports and resumed retry waits with lease ownership checks before updating persisted retry timing. The existing transactional executor claim and observation/listing/count/progress commit boundaries remain authoritative. No public API or schema change is needed. No approved deviations.

Twelve new worker API tests use temporary SQLite, controlled clocks, synthetic adapters and real child processes killed with SIGKILL. They exercise interruption before a listing commit, between commits, before terminal persistence, and after a request commit before IPC acknowledgement; competing expired-lease reclaim; stale observation fencing; persisted Retry-After timing; repeated interruption consuming the saved budget; cancellation and immutable succeeded/failed/partial/cancelled outcomes. Test fixtures bundle with the existing Vite API into a temporary directory and introduce no production fault hooks.

Private observation history stays private. Evidence for avoiding duplicate effects is stable saved listing identities/fields, exact committed counts and no repeat fetch of already committed details. SIGKILL models abrupt worker death; power-loss durability and cross-platform release verification are outside this slice.
