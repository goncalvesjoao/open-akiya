## Implementation and decisions

Explicit address/place search uses a fixed validated preload operation and a worker-owned replaceable Nominatim HTTP boundary. Choosing a current match synchronizes the existing area center, coordinates and map circle, preserving radius and Show unavailable. Search and selection never start imports. Manual selections, query edits and clearing invalidate old matches/responses. Existing listing-location uncertainty and job contracts are unchanged.

Optional self-hosted Nominatim avoids a paid subscription and the public OSMF endpoint's aggregate application limits. The public endpoint is rejected. This requires optional provider provisioning; map and coordinate selection work without it. [Setup and official policy references](../location-search.md) describe Japanese/Latin coverage, HTTP transport, privacy, attribution, throttling and credentials. No approved deviations. A production Japanese provider database was not installed or live-queried.
